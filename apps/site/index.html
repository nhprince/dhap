One Source of Truth. Four Seamless Steps.

No more taking separate screenshots or duplicating edits across image tools and wikis.

1

Record or Import

Capture your display with native recorders or import common MP4, WebM, and MOV video recordings.

2

Extract Keyframes

Heuristic scene-detection proposes candidate moments with exact timestamps for your review.

3

Annotate & Redact

Add callout badges and arrows. Apply irreversible pixel redactions that permanently destroy sensitive data.

4

Multi-Format Export

Generate clean GitHub-ready Markdown, standalone interactive HTML guides, and PDF documentation.

Crafted for Privacy, Velocity, and Control

Built with safe, modern Rust to deliver native performance and reliable exports.

🛡️

100% Local-First & Offline

No mandatory accounts, subscriptions, or cloud uploads. Your recordings and documentation stay on your machine.

⬛

Irreversible Redaction

Redactions are baked destructively into exported image pixels. Sensitive credentials cannot be recovered via browser DevTools.

⚡

Rust Engine & CLI

Fast frame extraction, schema validation, and multi-format exports powered by safe compiled Rust.

🤖

AI is Strictly Optional

Zero AI dependencies for all core features. When enabled, AI generates suggestions that you review and approve.

Quick Start with Dhap CLI

Inspect recordings, validate projects, and export guides in automated pipelines.

# Clone and build the Dhap workspace
git clone https://github.com/nhprince/dhap.git
cd dhap
cargo build --release

# Validate a .dhap project
./target/release/dhap validate fixtures/sample_guide.dhap

# Export Markdown and Standalone HTML documentation
./target/release/dhap export fixtures/sample_guide.dhap --format markdown,html --output-dir ./dist_docs
